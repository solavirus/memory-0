# Image Prompt Template

Use this template as a starting point. Replace bracketed fields.

---

Create **one standalone page** of a minimalist vertical Chinese comic, aspect ratio 9:16.

## Character reference

Preserve the fixed protagonist exactly:
- black simple stick / brush body
- white circular head
- bright blue triangular hat
- one orange star on the hat
- deliberately minimal design

Use the repository character reference assets as identity anchors.

## Visual style

Extremely minimal single-scene comic.

- off-white paper background
- rough black hand-drawn / marker lines
- sparse blue and orange accents
- lots of empty space
- few objects
- simple silhouettes
- no photorealism
- no 3D
- no decorative clutter
- not an infographic
- not a poster layout
- not a collage
- not multiple panels inside one image

The page should feel light and readable immediately.

## Hard constraints

Do not add:
- extra furniture
- shelves
- plants
- cats
- posters
- piles of notes
- decorative UI
- background characters
- extra speech bubbles

unless explicitly required by this page's story.

Use only the minimum elements required to communicate the beat.
