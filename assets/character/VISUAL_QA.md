# Visual QA

Use this after every generated page.

## A. Character identity — must pass

- [ ] blue triangular hat is present
- [ ] orange star is present
- [ ] white circular head is present
- [ ] body remains black and simple
- [ ] no accidental redesign, hair, realistic face, or permanent costume
- [ ] silhouette still matches `character-base.svg`

If any item fails: regenerate.

## B. Minimalism — must pass

- [ ] one main scene only
- [ ] one main idea only
- [ ] background is mostly empty
- [ ] no decorative furniture or props added without narrative purpose
- [ ] no more than two speech bubbles in normal cases
- [ ] no infographic card grid
- [ ] no collage / multi-panel page

If the image feels "rich", it is probably already too busy.

## C. Story clarity

- [ ] page advances the story
- [ ] headline says what changed
- [ ] scene demonstrates rather than repeats the headline
- [ ] dialogue is short
- [ ] page can be understood in 2–4 seconds

## D. Series continuity

Across consecutive pages:
- [ ] protagonist scale is reasonably consistent
- [ ] hat shape and star placement are consistent
- [ ] line style is consistent
- [ ] paper/background tone is consistent
- [ ] secondary recurring characters remain visually consistent
- [ ] page composition varies enough to avoid feeling templated

## E. Text

- [ ] Chinese text is correct
- [ ] no accidental duplicated characters
- [ ] no malformed punctuation
- [ ] no tiny explanatory text
- [ ] title remains the largest text element

When generated text is wrong, prefer regenerating the page rather than accepting a visibly broken publication asset.

## F. Final rule

Before accepting the page, ask:

> What can I remove?

If something can be removed without losing meaning, the next version should usually remove it.
